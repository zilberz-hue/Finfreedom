# ניהול פיננסי נכון — דשבורד

דשבורד HTML יחיד למעקב חובות, הוצאות קבועות/משתנות, תזרים שבועי ותוכנית הבראה.
עמוד סטטי בודד (`index.html`) ללא תלות בבנייה — נפתח בכל דפדפן ומתאים לדיפלוי ישיר ב-Netlify.

## תכונות
- סיכום חובות, הוצאות קבועות/משתנות, וחלוקה עסק/בית
- מד התקדמות החזר מול היתרה המקורית
- סדר תקיפת חובות עם גרירה (drag & drop) לשינוי עדיפות
- תקציב חודשי חי לפי טווחי הכנסה
- ציר זמן לסגירה (תרחיש רצפה / ממוצע / חזק)
- תוכנית עבודה עם צ'קליסט ויעד תאריך
- לוח חיובים חודשי לפי תאריך הורדה + סיכום שבועי עם סימון "שולם"
- סנכרון בין מכשירים דרך JSONBin

## שימוש
פתח את `index.html` בדפדפן. כל הנתונים נשמרים מקומית בדפדפן (localStorage), ואפשר לסנכרן בין מכשירים דרך פאנל "סנכרון ענן".

## דיפלוי ב-Netlify
חבר את הריפו ל-Netlify. Publish directory: שורש הריפו. אין פקודת build.

## אבטחה
אין לשמור בקובץ מספרי חשבון, כרטיסי אשראי או סיסמאות. מפתח ה-JSONBin מוזן בדפדפן בלבד ואינו נשמר בקוד.
